T1 Learning Curves — Reading & Comparing marks: 4 (every year) ▼

🔴 Bad Model (KNN in past papers)

  • Training score starts HIGH (~0.75+)
  • CV score starts LOW and stays LOW (~0.55–0.60)
  • Big GAP between the two lines = Overfitting / High Variance
  • Model memorises training data, fails on new data

🟢 Better Model (SVM in past papers)

  • Training and CV scores converge
  • Both lines close together at end (~0.65–0.70)
  • Small gap = model generalises well
  • Higher CV score = better real-world predictions
Standard answer template: "The SVM model would provide better prediction results because its training score and cross-validation score converge and are close together, indicating that the model generalises well to unseen data. The KNN model shows a large gap between its training score and CV score, which is an indication of overfitting — the model performs well on training data but poorly on new data."
T2 k-Means Clustering Steps marks: 5 ▼
  1. Choose k — decide how many clusters to create
  2. Initialise centroids — randomly place k cluster centres in the data space
  3. Assign data points — each data point is assigned to the nearest centroid (using Euclidean distance)
  4. Update centroids — recalculate each centroid as the mean of all data points assigned to it
  5. Repeat steps 3–4 until centroids no longer move (convergence) or max iterations reached
Silhouette score is used to find the best k. Higher silhouette = better defined clusters. Plot silhouette vs k and pick the k with highest score.
T3 Gini Impurity Calculations (Decision Tree) marks: 11–12 ▼
Gini(node) = 1 − Σ(pᵢ)²
Weighted Gini(feature) = (n_left/n_total) × Gini(left) + (n_right/n_total) × Gini(right)

The feature with the LOWEST weighted Gini is the root (best split).

Example from past papers (HBP vs Age<48 → Heart Attack):
7 records total. Split on HBP: Yes=5, No=2. Split on Age<48: Yes=5, No=2.
Calculate Gini for each child node, then weighted sum. The feature with lower weighted Gini is the root. 
# HBP split: Yes(5 records), No(2 records)
# HBP=Yes: HA=[Yes,No,Yes,No,Yes] = 3 Yes, 2 No → p_yes=3/5, p_no=2/5
gini_yes = 1 - ((3/5)**2 + (2/5)**2)  # = 1 - (0.36 + 0.16) = 0.48

# HBP=No: HA=[No,No] = 0 Yes, 2 No → p_yes=0/2, p_no=2/2
gini_no = 1 - ((0/2)**2 + (2/2)**2)   # = 1 - (0 + 1) = 0

# Weighted Gini for HBP
weighted_hbp = (5/7) * gini_yes + (2/7) * gini_no
# = (5/7)*0.48 + (2/7)*0 = 0.343
Do the same for Age<48. The feature with the LOWER weighted Gini is chosen as root. Show ALL calculations for full marks.

T5 Precision / Recall / F1 — Manual Calculation marks: 6 (ST1 2024) ▼
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
F1 = 2 × (Precision × Recall) / (Precision + Recall)
Example (ST1 2024): 12 actually at risk. Model flags 8. Of those 8, 3 were wrong (FP).
→ TP = 8 − 3 = 5  |  FP = 3  |  FN = 12 − 5 = 7
→ Precision = 5/(5+3) = 0.625
→ Recall = 5/(5+7) = 0.417
→ F1 = 2×(0.625×0.417)/(0.625+0.417) = 0.5

from sklearn.model_selection import learning_curve

def plot_learning_curve(model, name, X, y):
    train_sizes, train_scores, cv_scores = learning_curve(
        model, X, y, cv=5, train_sizes=np.linspace(0.1,1.0,10),
        scoring='accuracy')

    plt.figure(figsize=(8,5))
    plt.plot(train_sizes, train_scores.mean(axis=1), '--', label='Training score')
    plt.plot(train_sizes, cv_scores.mean(axis=1),    '-',  label='Cross-validation score')
    plt.title(f'Learning Curve for the {name} Classifier')
    plt.xlabel('Training Set Size')
    plt.ylabel('Accuracy Score')
    plt.legend()
    plt.show()

for name, model in models.items():

I1 Training Accuracy vs Testing Accuracy marks: 1–2 ▼
Situation What it means What to write
Train ≈ Test (both high) Model generalises well "The training accuracy of X% is close to the test accuracy of Y%, indicating the model generalises well to unseen data and is not overfitting."

I2 Precision, Recall & F1-Score marks: 2–3 ▼
Metric Definition Template answer
Precision Of all predicted positives, how many were actually positive?
TP / (TP + FP) 		"A precision of X means that X% of the customers predicted to leave actually left. A high precision means few false alarms."
Recall Of all actual positives, how many did the model find?
TP / (TP + FN) 		"A recall of X means the model correctly identified X% of all actual churned customers. A low recall means many churners were missed."
F1-Score Harmonic mean of Precision and Recall. Best single metric for imbalanced data. "The F1-score of X represents the balance between precision and recall. It is the preferred metric when the dataset is imbalanced."
Support Number of actual samples in each class in the test set. "Support shows how many test samples belong to each class."
Good F1 = close to 1.0. Above 0.80 is generally good. The question always says "select the model with highest F1" — don't pick by accuracy.
I3 Confusion Matrix — Reading It theory ▼ 
#          Predicted: No   Predicted: Yes
# Actual: No    [TN]            [FP]
# Actual: Yes   [FN]            [TP]

# TN = True Negative  (correctly predicted NO)
# TP = True Positive  (correctly predicted YES)
# FP = False Positive (predicted YES, actually NO) — Type I Error
# FN = False Negative (predicted NO, actually YES) — Type II Error
In a churn model: FN is dangerous — a customer who will leave that we miss. High recall = fewer FN. In medical models, FN = missed diagnosis = most costly.

I6 Outliers / Boxplots — What to Say marks: 1–3 ▼
Spotting outliers: Data points outside the whiskers of a boxplot are outliers. The IQR method: any value < Q1 - 1.5×IQR or > Q3 + 1.5×IQR is an outlier. 
# Fix outliers using IQR method
for col in ['Weight','Length','Width','Thickness']:
    Q1  = df[col].quantile(0.25)
    Q3  = df[col].quantile(0.75)
    IQR = Q3 - Q1
    df  = df[(df[col] >= Q1 - 1.5*IQR) & (df[col] <= Q3 + 1.5*IQR)]
print("Shape after outlier removal:", df.shape)

Why IQR? It is a robust method that does not assume a specific distribution. It removes extreme values that could negatively affect model training.
